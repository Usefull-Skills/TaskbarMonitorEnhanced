Taskbar Monitor Enhanced v1.7.8
One versioned unsigned per-user Setup. Safe same-root upgrade from the pinned
immutable official v1.7.7. Adds an optional Windows scheme-based warning sound
for CPU/GPU/disk temperature threshold notifications; silent by default.
To enable: Settings > Alerts > Play Windows warning sound. Use Test warning
sound there to preview it safely without heating your computer.
The sound follows Windows user sound scheme and output volume; a muted
Windows endpoint can suppress it. The configured cooldown, hysteresis and
quiet hours continue to apply. Glass zero alpha / hot red and all settings
are preserved; no extra installation or kernel driver is bundled.
